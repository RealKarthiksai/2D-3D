# 2D-3D — Intelligent Room Capture (Part 1 Mobile App)

This repository contains **Part 1** of the 2D-3D Room Scanner Program: native mobile capture applications and SDKs with on-device spatial intelligence.

## Components
- [`capturekit/`](capturekit/README.md) — Cross-platform phone capture SDK (iOS Swift + ARKit, Android Kotlin + ARCore, C++20 core, Python `ckit` bundle tools).
- `docs/program-spec/` — Part 1 specification (`part1-room-capture.md`), the two-part overview, frozen conventions, and the Part 2 contract reference.

*(Downstream Part 2 — 3D Processing & Reconstruction is maintained separately in `roomscan-recon`)*
